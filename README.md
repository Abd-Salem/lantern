# lantern

Lantern is a hands-on project where we practice Git version control and collaboration on GitHub, including branching, merging, pull requests, and syncing with push and pull. It is a tiny command-line task tracker.

## Install and usage

```bash
git clone https://github.com/Abd-Salem/lantern.git
cd lantern
python3 lantern.py list
```

## Commands

- `add <title>`: add a new task
- `list`: show all tasks
- `list --done`: show only completed tasks
- `list --sort`: show tasks sorted by title
- `export --csv`: print tasks as CSV

Full details are in [docs/usage.md](docs/usage.md).
