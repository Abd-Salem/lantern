# Usage

Lantern is a tiny command-line task tracker.

## Commands

- `python lantern.py add "Buy milk"`: add a new task
- `python lantern.py list`: show all tasks
  If there are no tasks, it prints `No tasks yet.`

Tasks are saved in `tasks.json` in the current folder.

### list --done

Shows only completed tasks.

    lantern list --done
